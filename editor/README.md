# Blyx Conformal

Calibrate a regression interval from held-out errors and measure coverage on a separate test set.

This extension includes the Blyx Conformal 0.1.0 source, a runnable example and completions for its public functions. It uses the Blyx Language extension for syntax highlighting and execution.

## Run in the editor

1. Open an empty file named `conformal-demo.blyx`.
2. Type `blyx-conformal-demo` and select **Conformal — runnable example**. You can also use **Snippets: Fill File with Snippet**.
3. Choose **Blyx: Run File** from the command palette. Change an argument near the end of `fn main()` to try another input.

Expected output

```text
2
18
22
```

## Use Conformal in a project

Extract the starter into a new folder. It contains `main.blyx`, the licensed framework source in `vendor/conformal`, and a VS Code task. With the Blyx 0.2.1 compiler and host toolchain installed, run `blyxc native-run main.blyx` from that folder. Type `blyx-conformal-` in a Blyx file to see the framework completions. [Download the starter ZIP](https://github.com/Rahulchaube1/blyxxxx/releases/download/framework-editors-v0.1.0/blyx-conformal-starter-0.1.0.zip)
