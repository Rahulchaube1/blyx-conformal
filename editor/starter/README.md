# Conformal starter

Calibrate a regression interval from held-out errors and measure coverage on a separate test set.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Conformal** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
2
18
22
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/conformal) · [View the release](https://github.com/Rahulchaube1/blyx-conformal/releases/tag/v0.1.0)
